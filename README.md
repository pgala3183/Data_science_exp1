# Data Science Experiments (CMPE 297)
Video explainations: https://drive.google.com/drive/folders/13iLfY5BxwPUcunDKCxSe5806nXlYZZQH?usp=sharing

## How to explore

1. Open any experiment folder.
2. Follow that project’s `README` for setup, ports, and tests.
3. Prefer a fresh virtualenv / `npm install` per project — dependencies are not shared at the repo root.

## Stack (typical)

Python (FastAPI, scikit-learn, AutoGluon) · React + Vite · TypeScript where noted
